## Featured project

### [Smart Irrigation Manager](https://github.com/LittleNemo2/Smart-Irrigation-Manager)
A full-stack Spring Boot app that decides when to water a landscape. A rules-based engine combines soil moisture, live weather forecasts, and evapotranspiration to decide each zone's watering. It has role-based security, search, CSV reports, and unit tests, and it's deployed on Azure Container Apps with PostgreSQL through automated scripts that roll back if a deploy fails.
